# Workshop

Módulo de gestión de reparaciones y servicios para **Odoo 20 Community**.

## Objetivo

Desarrollar un módulo genérico para talleres de reparación y servicios, con órdenes de trabajo, procedimientos reutilizables y versionados, control de ejecución, calidad, integración con inventario y propuestas comerciales revisables.

El proyecto sigue un enfoque incremental: alcance funcional definido, implementación acotada, pruebas verificables y revisión humana de los cambios.

## Estado

En preparación. La implementación del módulo todavía no ha comenzado.
